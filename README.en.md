Rita-Berenice was developed primarily for personal use as a self-hosted AI character chat framework. Its goal was to let users keep ownership of their character and conversation data, connect the LLM providers they choose, and manage long-running conversational context and memory in their own database.

The code in this repository remains public as a record of the implementation and architecture at that point in development. **Do not use this repository for a new installation or production use.** A future public release intended for general users will be distributed through a separate project and release channel.

## About the project

At the time of this snapshot, Rita-Berenice was developed around these ideas:

- User-owned character, profile, and conversation data
- BYOK connections to multiple LLM providers
- Persistent storage with PostgreSQL/pgvector
- A memory layer for reusing past events and context in long-running conversations
- Separate management of character settings, lore, history, recaps, and chat records
- A self-hosted structure that users can install and modify themselves

Implementation details remain available in the source code and Git history of this repository.
